[COLOR purple][B]Private build 1.0.32.4[/B][/COLOR]
- Read Fen Light's selected source language from a per-thread context. Late
  background results remain filtered correctly without relying on a shared
  Kodi window property for current Fen builds.
- Retain the legacy window-property fallback for earlier Fen versions.

[COLOR purple][B]Private build 1.0.32.3[/B][/COLOR]
- Added language-aware release-name filtering driven by Fen Light's preferred
  external-scraper source language setting. English is the default, with Any
  Language and supported non-English choices available from Fen Light.
- Explicitly tagged releases in another language are filtered while untagged
  releases remain available; multi-language releases remain available. The
  existing foreign single-audio setting remains the fallback for other Kodi
  add-ons that do not provide the Fen Light preference.
- The Fen Light preference is honored only during an active Fen scrape, so it
  does not leak into another add-on using CocoScrapers in the same session.

[COLOR purple][B]Private build 1.0.32.2[/B][/COLOR]
- Compared with the original 1.0.32 source, added optional provider
  integrations for Prowlarr, Rutor, and ShowRSS, and updated the existing
  EZTV, TorrentGalaxy, Torrentio, and TorrentQuest integrations.
- Added provider settings and English labels for those integrations. Bitsearch,
  EZTV, TorrentQuest, Rutor, and ShowRSS now default on for the working setup;
  Prowlarr remains opt-in because it needs a configured URL and API token.
  Existing foreign single-audio filtering remains enabled by default and is
  applied by the updated provider modules.
- Hardened the shared HTTP client: per-request openers replace process-global
  opener changes, default request timeouts are reduced to 10 seconds, header
  handling is corrected, and Cloudflare cookie racing uses three short-lived
  daemon workers instead of fifteen persistent workers.
- Replaced the global `ThreadPoolExecutor` with a per-batch queue using up to
  10 daemon workers. Each batch is completed before the scraper returns, while
  the compatibility shutdown function no longer owns persistent workers.
- Removed the fixed two-second Torrentio pack delay and replaced it with a
  short state-aware wait; TorrentQuest page-two requests now have a five-second
  timeout; EZTV logging is corrected; and TorrentGalaxy was rebuilt around its
  JSON endpoint with mirror fallback and pack parsing.
- Fixed the PirateBay scraper's `log_utils` import scope, which could produce
  an `UnboundLocalError` on the normal successful-query path.
- The complete private package, rather than the old partial overlay, contains
  all of the above changes.
