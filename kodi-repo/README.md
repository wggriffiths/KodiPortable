# Tinkerer Kodi repository output

This directory is the static repository Kodi reads after the
`repository.tinkerer` ZIP has been installed.

It is generated by:

```powershell
.\build-kodi-repository.ps1
```

The builder rebuilds Fen Light and CocoScrapers, copies them into the
versioned `zips\` directories, packages `repository.tinkerer`, and generates
`addons.xml` plus `addons.xml.md5`.

The GitHub Pages repository URL is:

`https://wggriffiths.github.io/KodiPortable/`

Install `repository.tinkerer-1.0.1.zip` once through
Kodi's **Install from zip file** menu. After that, Kodi can discover updates
from this repository.

The ZIPs in this directory are publishable artifacts and are intentionally
tracked so the public GitHub repository can serve them directly.
